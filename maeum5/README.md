# 마음 5분 매트릭스 — 셀프케어 보조 앱

화면은 세 개예요. 색은 네이버풍 초록(`src/index.css`의 `--color-brand-*`), 로고는 새싹(`public/favicon.svg`)이에요.

**`/` 마음 체크 (메인)**: PHQ-9 9문항을 한 화면에 한 문항씩 카드형으로 답하면, 점수 카드와 "지금 바로 해보는 5분 행동" 3개, 출시 전 유료 상품(30일 보고서·전문가 상담) 카드가 나와요.
- 추천 행동은 Claude가 근거표의 10개 행동 중에서만 골라요(JSON 스키마의 id 목록으로 제한). 키가 없거나 호출이 실패하면 문항별 규칙으로 골라서, 결과 화면은 항상 떠요.
- 9번 문항(자해 생각)이 1점 이상이면 모델을 거치지 않고 109·1577-0199 안내를 결과 맨 위에 띄워요. 10점 이상이면 전문 상담 안내 카드가 나와요.
- 질문은 "지난 2주 동안, 아래 일이 얼마나 자주 있었나요?", 답은 "전혀 없었어요 / 며칠 있었어요 / 7일 이상 있었어요 / 거의 매일 있었어요"로 쉽게 바꿨어요. 원래 한국어판의 "방해 받았다" 표현이 헷갈려서예요. 빈도 기준(0~3점)은 원문과 같아서 점수 구간도 그대로예요. 문항 9개의 내용은 바꾸지 않았어요.
- 점수 구간은 PHQ-9 표준 기준(0–4·5–9·10–14·15–19·20–27)이고, 문구는 판정이 아닌 안내로 썼어요. 문항·구간·문구는 `src/content.js`의 `PHQ9`에 있어요.
- **이번 달, 나와 비슷한 사람들**: 결과 화면에 이번 달(1일부터) 점검한 사람 중 나와 비슷한 점수(±2점)였던 사람 수와, 내가 가장 자주 방해받은 문항(2점 이상, 9번 제외)이 같이 2점 이상이었던 사람 수를 보여줘요. "나만 이런 게 아니구나"를 숫자로 알려주려는 장치예요. 근거: 사람들은 남들의 부정적인 감정을 실제보다 적게 어림하고, 그럴수록 외로움이 컸다는 연구(Jordan et al., 2011). 결과 화면은 **실제 응답만** 세고 나는 빼요. 이번 달 첫 점검이면 "내가 첫 번째"라고 알려줘요.

**`/pricing` 요금 안내**: 무료 기본 이용 · 30일 보고서 5,900원 · 전문가 상담 39,000/59,000원 · 기관 프로그램 200만 원(100명·30일)과 기관 구성표. 가격은 모두 "검증 예정 제안가"로 표시하고, 유료 상품마다 구분할 점(AI 보고서는 전문가 검토가 아님, 최소 기록 14일, 상담 포함 여부 등)을 적었어요. 내용은 `src/content.js`의 `PLANS`에서 고쳐요.
- 보고서·상담 카드의 "이 가격이면 써볼래요 / 더 싸면 써볼래요 / 필요 없어요" 버튼은 판매가 아니라 지불 의향 확인용이에요. 응답 수는 `GET /api/interest`로 볼 수 있어요.
- 9번 문항이 1점 이상인 결과 화면에는 유료 상품을 띄우지 않아요.

**`/demo` 시연 대시보드**
1. 상단 페르소나 전환: **A 취준생(민준, 28, 취업 준비 3년째)** / **B 대학생(서연, 21)**
2. **이번 달, 민준(서연)과 비슷한 사람들**: 페르소나의 가상 2주 점검 점수(민준 14점, 서연 9점)를 이번 달 응답과 비교해 비슷한 점수 인원(큰 숫자), 같은 부분이 힘들었던 인원, 점수별 인원 막대(비슷한 점수만 초록)를 보여줘요. 표로 보기와 근거 보기가 있어요. 발표 때 숫자가 보이도록 **시연용 가상 응답**(이번 달 1일부터 오늘까지 하루 10~19명, `seed.js`의 `virtualSurveys`)에 실제 응답을 더해 세고, 화면에 "가상 응답 N명 + 실제 응답 M명"을 나눠 적어요. 실제 결과 화면에는 가상 응답을 넣지 않아요.
3. 선택한 페르소나의 최근 7일 수면·카페인·심박 차트, 시간대별 마음 패턴, 상관 분석
4. 웹캠 심박 측정(rPPG): 캔버스 오버레이 애니메이션, 평소 대비 변화 표시
5. AI 대화(Claude): 대화로 감정·시간대·장소·수면·카페인을 뽑아 DB에 기록
6. 상황별 5분 루틴: 지금 추천 카드 · 감정별 행동표 · 근거 자료 탭 (화면 문구에 '처방·치료' 없음)

## 실행

Node 22.13 이상이 필요해요.

```bash
cd maeum5
npm install
cp .env.example .env    # ANTHROPIC_API_KEY 넣기
npm start               # http://localhost:5173
```

- 키가 없어도 화면, 미리 쌓아 둔 대화, 차트, 심박 측정은 모두 돌아가요. 새 대화를 보낼 때만 키가 필요해요.
- `npm test` — 심박 추정, 통계 게이트, 위험 표현 감지, 화면 문구 검사
- `npm run reset` — 서버를 끈 뒤 실행하면 DB를 지우고, 다음 `npm start` 때 오늘 기준 14일 시연 데이터를 새로 만들어요
- `npm run simulate -- A 6` — 서버를 켠 상태에서 실행하면 Claude가 페르소나 A를 연기하며 챗봇과 6번 대화하고, 그 기록이 DB에 쌓여요

## 웹에 올리기 (배포)

공개 주소에는 `npm start`(개발 서버)를 쓰면 안 돼요. 개발 서버는 DB 파일까지 내보내요. 배포할 땐 빌드한 화면만 내보내는 배포 모드로 실행해요: `npm run build` 다음 `npm run serve`.

**Render (무료, GitHub 연결)** — 무료 플랜 조건은 바뀔 수 있으니 가입할 때 확인하세요.

1. render.com에 GitHub로 가입 → New → Web Service → 저장소 `lryse51618/MarkitDown`, 브랜치 `claude/loving-mendel-887a62`
2. Root Directory `maeum5` · Build Command `npm install && npm run build` · Start Command `npm run serve` · Instance Type Free
3. Environment Variables: `NODE_VERSION` = `22`, `ANTHROPIC_API_KEY` = 콘솔 키
4. 배포가 끝나면 `https://<서비스 이름>.onrender.com` 주소가 생겨요. HTTPS라 웹캠 측정도 돼요.

무료 플랜은 한동안(보통 15분) 접속이 없으면 잠들고, 다음 첫 접속에 1분쯤 걸려요. 시연 직전에 한 번 열어 두세요. 디스크도 유지되지 않아서 서버가 다시 켜지면 DB가 그날 기준 시연 데이터로 돌아가요. 쌓은 대화를 남기려면 유료 디스크를 붙이거나 내 컴퓨터에서 실행하세요.

**내 Mac에서 임시 공유 (계정 없이)** — `npm run serve`를 켠 채로 `brew install cloudflared` → `cloudflared tunnel --url http://localhost:5173` 을 실행하면 `https://….trycloudflare.com` 주소가 나와요. Mac이 켜져 있는 동안만 열려요.

공개 주소는 누구나 대화를 보낼 수 있어서, 하루 300번이 넘으면 서버가 대화를 막아요(`server.js`의 `MAX_CHATS_PER_DAY`). Anthropic 콘솔에서 월 사용 한도도 걸어 두세요.

## 시연 순서 (라이브 대화 없이도 됨)

0. 메인(`/`)에서 2주 마음 점검을 한 번 해요. 결과 화면 "이번 달, 나와 비슷한 사람들"에 실제 응답 기준 숫자가 나와요(서버를 새로 켠 직후면 "내가 첫 번째"). 팀원이 미리 몇 번 점검해 두면 숫자가 실제로 쌓여요. 이어서 `/demo` 맨 위 패널에서 "민준과 비슷한 점수 N명"을 보여주며 같은 장치를 가상 응답 규모로 설명해요.
1. A(취준생): 아침 기분이 가장 낮고(무기력·우울), 밤에는 고독·소외감이 많아요. "잠을 더 잔 날 기분이 높은 경향"이 보여요. 아침 칸을 누르면 '발가락 30초 꼼지락' 카드가 떠요.
2. B(대학생)로 전환하면 모든 숫자가 바뀌어요. 밤 불안이 가장 크고 "카페인을 많이 마신 날 밤 잠이 짧아지는 경향"이 보여요. 밤 칸을 누르면 '두 번 들이쉬고 길게 내쉬기', '잠들기 전 5분 할 일 적기' 카드가 떠요.
3. 심박 측정 15초 → 평소 대비 +10 이상이면 호흡 루틴을 권하고 오늘 기록에 저장해요.
4. (키가 있으면) 대화 한 줄 → "대화에서 기록됨: 불안·과부하 · 밤 · 카페인 3잔" → 카드가 바로 바뀌어요.
5. 근거 자료 탭: 행동마다 연구 2~3편과 근거 등급(A/B/C)이 보여요.

## 심사 대비 설계 포인트

- **LLM의 역할을 좁게 잡았어요.** Claude는 공감하며 답하고 JSON 스키마에 맞춰 값을 뽑는 일만 해요. 행동 추천은 근거를 확인한 표에서 규칙으로 고르기 때문에, 모델이 지어낸 조언은 카드로 나가지 않아요. 다만 대화 답변 문장 자체는 여전히 생성되는 글이에요.
- **안전장치는 2단이에요.** 직접적인 위험 표현은 정규식이 잡아 모델을 거치지 않고 109와 1577-0199를 안내해요. 간접 신호는 모델이 `risk` 필드로 판단해요.
- **통계는 보수적으로 말해요.** 기록이 14일 미만이면 분석하지 않고, |r| ≥ 0.5(14개 표본의 p<.05 기준인 r≈0.53에 가까운 값)인 결과만 "경향"으로 보여줘요. 일별 기록은 자기상관이 있어서 p값은 표시하지 않아요. 다중회귀는 표본이 쌓이기 전까지 쓰지 않아요.
- **감정 분석에 KoBERT를 쓰지 않아요.** Claude 구조화 출력이 감정 5종(무기력·우울, 불안·과부하, 분노·울분, 고독·소외감, 괜찮음)을 정해진 선택지 안에서만 분류해요.
- **rPPG는 POS 알고리즘(Wang et al., 2017)을 써요.** 계산은 브라우저 안에서만 하고 영상은 저장하지 않아요. 조명과 움직임에 민감하고 의료용 측정이 아니에요.
- **근거 등급:** A는 이 행동을 직접 다룬 메타분석이 있음, B는 직접 다룬 실험이 있음, C는 원리 근거만 있음(발가락 꼼지락, 메시지 다시 읽기). C등급은 근거 탭에 솔직하게 적어 뒀어요.

## 무료 이용자 비용과 보고서 공헌이익 (가정)

모두 **우리의 비용 가정**이에요. 1달러 = 1,400원, Claude 공개 단가(2026-10 기준, 100만 토큰당 Opus 5.5 입력 $4·출력 $20·캐시 읽기 $0.20, Haiku 5.5 입력 $0.10·출력 $0.50)로 계산했어요. 토큰 수는 추정이라, 키를 넣고 돌린 뒤 서버 로그(`[chat]`, `[survey]`의 `in / cache_read / out`)로 실제 값을 재서 표를 고쳐 주세요.

| 항목 (토큰 가정) | Opus 5.5 (현재) | Haiku 5.5 |
|---|---|---|
| 마음 체크 추천 1회 (입력 1,000 · 출력 250) | 약 13원 | 약 0.3원 |
| AI 대화 1턴 (입력 4,000 중 3,000 캐시 · 출력 300) | 약 15원 | 약 0.4원 |
| 30일 보고서 생성 1회 (입력 20,000 · 출력 2,000) | 약 170원 | 약 4원 |
| 무료 이용자 1명·월, 가볍게 (체크 4회 + 대화 20턴) | 약 350원 | 약 9원 |
| 무료 이용자 1명·월, 많이 (체크 8회 + 대화 100턴) | 약 1,600원 | 약 40원 |
| 무료 이용자 1,000명·월, 가볍게 | 약 35만 원 | 약 1만 원 |

여기에 서버비가 더해져요. Render 무료는 0원이지만 잠들고 DB가 초기화돼서, 실제 운영은 Starter($7)와 디스크부터 월 1만 원 안팎이에요. 고객 응대, 결제 수수료, 인건비, 개발·보안 고정비는 위 표에 넣지 않았어요.

**30일 보고서 1건(5,900원)의 공헌이익**은 결제 경로에 따라 달라져요. 웹 PG 수수료를 3%로 가정하면 Opus 기준 약 5,560원, Haiku 기준 약 5,720원이에요. 앱 인앱결제 15%로 가정하면 Opus 기준 약 4,850원이에요. 보고서 같은 디지털 상품은 앱에서 팔면 스토어 수수료(15~30%)가 붙어요. 애플은 실시간 1:1 상담 같은 사람 간 서비스에 다른 결제 수단을 허용해요(App Store 심사 지침 3.1.3(d)).

**무료 이용자 AI 비용을 보고서 판매로 메우려면**(가볍게 쓰는 경우, 웹 결제): Opus면 무료 이용자 100명 중 약 6명, Haiku면 1,000명 중 약 2명이 매달 보고서를 사야 해요. 모델 선택이 필요한 유료 전환율을 수십 배 바꿔요.

손익은 같은 기간 기준으로 `상품 공헌이익 합계 − 무료 이용자 지원비 − 고정비 = 예상 영업손익`으로 연결하고, 각 비용은 한 번만 넣어요. 지불 의향 응답(`GET /api/interest`)도 Render 무료 서버에서는 서버가 다시 켜지면 사라지니, 조사 기간에는 내 컴퓨터나 유료 디스크에서 운영하세요.

비용을 줄이는 장치도 넣어 뒀어요. 고정 프롬프트와 이전 대화는 캐시하고(캐시 읽기는 입력 단가의 5~10%), 그때그때 바뀌는 정보는 대화 끝에 system 메시지로 붙여서 캐시가 깨지지 않게 했어요. 추론 강도는 `effort: low`예요.
