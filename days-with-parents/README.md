# 남은 날들 (days with parents)

부모님 나이를 넣으면 앞으로 남은 달과 만남을 세어 보여주고, 함께한 날을 1년 달력에 한 칸씩 채우는 웹 사이트예요. 마음 5분(`maeum5/`)과는 따로 도는 별도 사이트예요.

- 서버가 없는 정적 사이트예요. 기록과 목소리는 이용자 브라우저(localStorage, IndexedDB)에만 저장되고 어디로도 보내지 않아요.
- 빌드가 필요 없어요. `public/index.html`을 바로 열어도 돌아가요.

## 화면과 주소

화면마다 주소가 있어서 브라우저 뒤로가기·앞으로가기·새로고침이 그대로 돼요.

| 주소 | 화면 |
|---|---|
| `#/start` | 시작 |
| `#/age` → `#/grid` → `#/count` | 나이 입력 → 지나간 달·남은 달 → 남은 만남 (각 화면 왼쪽 위 ← 로 이전 단계) |
| `#/home` | 지난 1년 달력, 남긴 기록, "오늘 뵀어요", "다른 날 기록하기" |
| `#/day/2026-11-06` | 그날 기록 (통화/만남, 한 줄, 목소리, 지우기) |
| `#/life` | 남은 시간 보기 |
| `#/settings` | 부모님 나이 바꾸기, 기록 파일로 내보내기·가져오기, 처음 화면 다시 보기, 모든 기록 지우기 |

## 원래 파일에서 고친 것

- 뒤로가기(앱의 ← 버튼과 브라우저 버튼 모두), 나이 다시 입력(설정), 기록 지우기, 다른 날 기록하기를 넣었어요.
- 날짜를 UTC로 저장해서 한국에서는 오전 9시 전 기록이 전날로 가고, 오늘 칸이 안 켜지던 문제를 고쳤어요.
- 목소리를 localStorage에 넣으면 몇 개만 녹음해도 용량(약 5MB)이 차서 IndexedDB로 옮겼어요. 아이폰 사파리 녹음 형식(mp4)도 그대로 재생돼요.
- 남은 기간을 "84세 − 지금 나이"가 아니라 **나이별 기대여명(2024년 생명표)**으로 계산해요. 예전 방식은 나이가 많을수록 크게 짧게 나왔어요(80세: 48번 → 116번). 84세를 넘으면 "-7%가 남았어요"가 나오던 문제도 같이 없어졌어요.
- 해가 바뀌면 부모님 나이가 한 살씩 자동으로 늘어요.
- 1년 달력 칸이 4px라 누를 수 없어서 12px로 키우고 옆으로 넘기게 했어요(오늘 쪽이 먼저 보여요).
- 화면 확대 금지를 풀고, 작은 글씨 대비를 4.5:1 이상으로 올리고, 키보드·화면 읽기 프로그램으로도 쓸 수 있게 했어요.

## 백업 (휴대폰을 바꿀 때)

설정의 **기록 파일로 내보내기**를 누르면 `days-with-parents-날짜.json` 파일에 기록과 목소리가 함께 담겨요. 새 휴대폰에서는 시작 화면의 "예전 기록 파일이 있나요? 가져오기"나 설정의 **기록 파일 가져오기**로 불러와요. 같은 날짜 기록은 파일 내용으로 바뀌고, 이 앱 파일이 아니거나 형식이 틀린 값(없는 날짜, 오디오가 아닌 데이터 등)은 버려요.

## 확인

```bash
node --test days-with-parents/lib.test.js
```

## Render에 올리기 (Static Site)

1. Render 대시보드 → **New → Static Site** → 이 저장소 선택
2. Branch: `claude/loving-mendel-887a62`
3. Root Directory: `days-with-parents`
4. Build Command: `echo "no build"`
5. Publish Directory: `public`

정적 사이트는 무료이고 CDN으로 바로 나가서, 마음 5분(무료 웹 서비스)처럼 잠들었다 깨는 로딩이 없어요. 코드를 바꾼 뒤에는 그 서비스에서 **Manual Deploy → Deploy latest commit**을 눌러요.

## 숫자와 출처

| 나이 | 남은 기간(기대여명, 남녀 평균) | 남은 만남(연 12회) |
|---|---|---|
| 60세 | 약 26.0년 | 313번 |
| 68세 | 약 19.0년 | 229번 |
| 80세 | 약 9.7년 | 116번 |
| 90세 | 약 4.5년 | 55번 |

- **기대여명:** 통계청(국가데이터처) 「2024년 생명표」(2025년 12월 발표). 40·60·65·80세 값(남/여)은 보도자료를 인용한 기사로 확인했고, 70·90·100세 이상 값은 보도자료 표를 옮긴 자료에서 가져왔어요. 발표 전에 KOSIS '완전생명표(1세별)'로 한 번 더 확인해 주세요. 표의 나이 사이는 직선으로 잇고, 어머니·아버지를 묻지 않아서 남녀 값의 평균을 써요(70세 남녀 전체 17.5년과 0.15년 차이). 값은 `public/lib.js`의 `LIFE_TABLE`에 있어요.
- **왕래 연 12회:** 한국복지패널(한국보건사회연구원) 제19차 조사 보도 기준, 따로 사는 부모와 최근 1년 왕래 횟수의 중윗값이에요(평균 42회). 전화 통화는 중윗값 52회, 평균 106회였어요.
